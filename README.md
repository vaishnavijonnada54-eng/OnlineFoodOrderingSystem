# 🍔 FoodExpress – Online Food Ordering System

## 📌 Project Overview

FoodExpress is a simple and student-friendly Online Food Ordering System developed using HTML and CSS. The application provides an easy-to-use interface where users can browse different food items, view their selected items in a cart, and proceed to checkout.

The main aim of this project is to provide a simple, convenient, and visually appealing food ordering experience with an organized interface and easy navigation between different modules.

## 🎯 Objectives

- To develop a user-friendly online food ordering interface.
- To provide a simple login interface for users.
- To display different food items with images and prices.
- To allow users to manage their selected food items through a cart.
- To provide an order checkout interface.
- To maintain a consistent and attractive user interface.

## ✨ Modules

### 1. Login Module
- Provides a login interface for registered users.
- Accepts email address and password.
- Includes a Remember Me option.
- Provides a registration link.

### 2. Home Module
- Displays available food items in an organized grid layout.
- Includes food images, names, and prices.
- Provides an Add to Cart button.
- Contains food items such as:
  - Veg Biryani
  - Chicken Biryani
  - Prawn Curry
  - Chicken Curry
  - Mutton Biryani
  - Butter Naan
  - Butter Chicken
  - Gulab Jamun
  - Mango Lassi
  - Samosas
  - Ice Cream
  - Veg Manchuria

### 3. Cart Module
- Displays selected food items.
- Shows food images, names, and prices.
- Provides quantity selection.
- Includes an option to remove items.
- Displays the total amount.
- Provides a Proceed to Order button.

### 4. Order Module
- Provides a checkout interface.
- Collects customer details.
- Accepts delivery address and mobile number.
- Provides payment method selection.
- Includes a Place Order button.

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in VS Code.

3. Make sure all HTML, CSS, and image files are present in the same project directory.

4. Open `login.html` in your browser.

5. Navigate through the Home, Cart, and Order modules.
